### 3. Key Product Decisions & Trade-Offs

| Decision | Chosen Approach | Why | Alternatives Considered |
| :--- | :--- | :--- | :--- |
| **Grounded AI Engine** | Server-side `gemini-3.8-flash` with `{ googleSearch: {} }` and `{ googleMaps: {} }` via `@google/genai` | Yields verifiable real-time citations, current event truth, and precise geographical coordinates with zero client-key exposure | Client-side API calls (violates security) or ungoverned LLMs (hallucinates recent events and places) |
| **Ergonomic Design Posture** | Mobile-phone posture on all screens with floating Vault Knob, 3D rotatable cards, and bottom dock | High aesthetic engagement, fluid gesture response, zero layout clutter, and intuitive navigation | Rigid desktop-only dashboard (poor smartphone experience) |
| **Admin Control Suite** | Direct dual-perspective preview ("View as User"), manual tier assignment modal, and instant revalidation | Enables immediate operational troubleshooting and instant VIP customer onboarding without SQL access | Read-only static dashboard (requires direct database intervention) |
| **Payment Gateway** | Live Paystack popup integration with HMAC-SHA512 signature validation | Proven compliance and security for both Nigerian Naira (NGN) and international USD cards | Simulated checkout (unacceptable for production launch) |
| **Book of Lies Breadth** | Comprehensive 40+ episode seed across 8 distinct philosophical chapters | Delivers a monumental literary canon that substantiates the Jadai Studios brand identity | Stubs or placeholder excerpts (violates the "Zero Chunk Code" rule) |

#### Grounded Agent Request Lifecycle:
1. User enters prompt in Ultron Assistant or PRIME Oracle with search or maps enabled.
2. Server route `/app/api/ai/grounded/route.ts` initializes `@google/genai` with `gemini-3.8-flash`.
3. If query involves places, directions, or geography, `tools: [{ googleMaps: {} }]` executes with geolocation coords.
4. If query involves current events, market data, or news, `tools: [{ googleSearch: {} }]` executes.
5. Response returns `groundingMetadata.groundingChunks` containing verified URLs, titles, and snippets.
6. Frontend dynamically displays answer text alongside interactive source cards and route directions.
